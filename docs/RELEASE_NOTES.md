Portly 0.5.0 提供串口、TCP客户端/服务端及UDP调试。

- 串口自动重连、DTR/RTS、常用及自定义波特率。
- 多会话左右/上下分屏、独立对比窗口、8通道波形。
- HEX/字符/二进制查看、原始文件分块发送、参数化命令和响应规则。
- 发送与执行历史，区分本地提交、设备响应、异常、超时和停止；载入历史只恢复草稿。
- 命令导入按UUID保留/复制/覆盖，先预览校验和备份，再事务提交。
- 有界日志、轮转、目录额度、索引检索及目录汇批，减少高吞吐写放大。
- UDP 连续发送处理系统背压，停止/断开取消尚未提交的数据报。
- Windows 修正窗口/引擎/COM 关闭顺序，主窗口等待创建中的比较窗口及子引擎实际退出。
- 正常退出等待任务、导入、日志、配置与历史排空，覆盖macOS关闭窗口和Cmd-Q。

附件包括macOS13+ M系列ARM64 DMG/ZIP、Windows x64与ARM64安装器/便携ZIP、同版本完整源码、校验和与验证报告。macOS为ad-hoc签名且未公证，Windows未Authenticode签名；请按实际架构选择。

源码Apache-2.0；第三方包括LGPL组件，许可及对应源码已随包提供，应用完整source.zip请与二进制一并保留。

已完成本机226项自动化回归与短时间Release校准。长时间压力测试按用户要求提前停止，没有30分钟或2小时通过结论。真实USB/串口驱动矩阵及所有系统版本仍需实机验收，详情见仓库docs/VALIDATION.md。
